# Security Case Investigations

A collection of structured case-study investigations covering cybercrime, ransomware, cryptocurrency tracing, blockchain evidence, darknet investigations, and forensic psychology.

The repository focuses on **investigative reasoning**: separating verified facts from interpretation, following evidence across sources, documenting limitations, and explaining what the available evidence can—and cannot—establish.

## What This Repository Demonstrates

- Researching complex public cases from multiple sources
- Building evidence-based timelines
- Analyzing cryptocurrency and blockchain transactions
- Understanding digital evidence in cybercrime investigations
- Distinguishing confirmed facts from inference or attribution
- Documenting investigative limitations instead of overclaiming
- Applying forensic and investigative concepts to real-world cases
- Communicating findings in a structured case-report format

## Evidence Discipline

These studies deliberately distinguish between **what the source evidence establishes** and what would require additional evidence. Blockchain records can demonstrate transaction activity, for example, but do not automatically establish the real-world identity of an address owner. Psychological concepts are used as analytical frameworks where appropriate and are not presented as retrospective clinical diagnoses.

## Scope & Transparency

This repository contains **written analyses of publicly documented cases and coursework-based case studies**. It does not represent first-hand law-enforcement investigations, private evidence access, or clinical psychological assessments.

Individual case files identify their scope and sources where applicable. Readers should consult the original primary sources for authoritative legal, investigative, or historical conclusions.
